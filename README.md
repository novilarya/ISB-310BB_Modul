## Penjelasan Kode
Pada minggu kedua ini difokuskan dalam penggunaan Javascript untuk memperbagus tampilan sebuah web. Dimana pada minggu kedua ini terdapat perubahan pada index.html dan penambahan file style.js
### index.html
Pada file ini dirubah dan ditambahkan konfigurasinya mulai dari bagian header yang terdapat menu untuk melihat wishlist dan mengubah tema tampilan apakah dark atau light. Ketika user mengklik button Wishlist maka otomatis akan memanggil fungsi tampilkanWishlist() pada script.js berdasarkan class btn btn-outline-warning btn-sm me-2. Selain itu, ketika user mengklik button untuk mengubah tema maka akan secara otomatis berubah baik menjadi dark mode atau light mode dengan id btn-theme.
Selain pada header, pada card di masing-masing produk juga terdapat penambahan aksi yaitu dapat membeli produk yang nantinya stok akan berubah -1 setiap kali pembelian dimana aksinya berdasarkan btn-detail-beli, serta ada juga button Wishlist untuk menambahkan barang tersebut ke wishlist yang dimana aksinya berdasarkan btn-wishlist.
### script.js

Selanjutnya, pada baris ke-9-19 merupakan berguna sebagai bagian untama untuk memberikan perintah tombol agar bisa mengganti tema web baik menjadi terang atau gelap.
