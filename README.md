A. Week 1 - HTML, CSS, Bootsrap
   Pada minggu ini dipelajari beberapa hal, diantaranya:
   1. HTML
      HTML adalah bahasa markup yang digunakan untuk membuat dan menyusun struktur halaman web. HTML menggunakan elemen dan tag untuk menentukan cara konten diatur dan ditampilkan pada browser
   2. Struktur Dasar HTML
      Ada beberapa struktur dasar HTML yang membentuk fondasi dari setiap halaman web, diantaranya:
      2.1. <!DOCTYPE html>, memberi tahu browser bahwa dokumen ini menggunakan HTML5.
			2.2. <html>, Elemen root dari dokumen HTML.
			2.3. <head>, Bagian yang berisi informasi meta tentang dokumen, seperti judul dokumen.
			2.4. <title>, Ini adalah judul halaman yang ditampilkan pada tab browser.
			2.5. <body>, Bagian berisi konten yang akan ditampilkan di halaman web.
      2.6. <h1> - <h6>, Tag heading digunakan untuk membuat judul.
      2.7. <a href="">, Hyperlink dan navigasi adalah elemen penting dalam HTML yang memungkinkan pengguna untuk berpindah antar halaman web serta menjelajahi konten dengan mudah.
      2.8. <img src="">/<video src="">/<audio src="audio.mp3">, Kita dapat menggunakan tag <img> untuk menyisipkan gambar, serta elemen-elemen, seperti <audio> dan <video>, untuk menambahkan file audio dan video ke halaman web.
      2.9. <ul>/<ol>/<dl>, daftar berurutan (ordered list) menggunakan tag <ol>, daftar tidak berurutan (unordered list) menggunakan tag <ul>, hingga daftar istilah (description list) menggunakan tag <dl>.
   4. CSS
      CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan layout halaman web. CSS bekerja bersama HTML untuk mengatur cara elemen-elemen HTML ditampilkan. Adapun 3 cara penggunaan CSS, diantaranya:
      4.1. Inline CSS: Menggunakan atribut style langsung pada elemen HTML.
      4.2. Internal CSS: Menggunakan elemen <style> dalam tag <head>.
      4.3. Eksternal CSS: Menggunakan file CSS terpisah.
   6. Bootstrap
      Bootstrap adalah framework CSS open-source yang digunakan untuk membangun website responsif dengan cepat dan mudah.
